⚡ EV Sales Analysis \& Prediction in India

📌 Project Overview



This project focuses on analyzing Electric Vehicle (EV) sales trends in India and predicting future EV sales using Machine Learning techniques.



With the rapid adoption of electric vehicles in India, understanding sales trends and forecasting future demand becomes important. This project performs data cleaning, exploratory data analysis (EDA), visualization, and machine learning prediction to analyze EV sales patterns.



The project helps in understanding how EV adoption is growing and how data-driven models can be used to predict future sales trends.



🎯 Objectives



The main objectives of this project are:



Analyze EV sales trends in India



Perform data cleaning and preprocessing



Conduct Exploratory Data Analysis (EDA)



Visualize EV sales patterns using graphs



Apply Machine Learning models to predict EV sales



📂 Dataset



The dataset contains information about Electric Vehicle sales in India.



Important features in the dataset include:



Date / Year



Vehicle Category



Electric Vehicles Sold



Total Vehicles Sold



This dataset allows analysis of EV adoption patterns across different vehicle categories.

🔎 Project Workflow

1️⃣ Data Collection



The EV sales dataset was imported into Jupyter Notebook.



2️⃣ Data Cleaning



The dataset was preprocessed by:



Checking missing values



Formatting columns



Removing unnecessary data



Preparing data for analysis



3️⃣ Exploratory Data Analysis (EDA)



EDA was performed to understand the EV sales trends using statistical summaries and visualizations.



Visualizations included:



EV sales distribution



Category-wise EV sales



Sales trend analysis



Comparative charts



4️⃣ Machine Learning Model



A Machine Learning model was implemented to predict EV sales.



Steps included:



Feature selection



Splitting dataset into training and testing data



Training the ML model



Evaluating prediction results



This helps in forecasting future EV sales trends based on historical data.



📊 Key Insights



Some key observations from the analysis include:



EV adoption in India is increasing steadily.



Certain vehicle categories contribute more to EV sales.



Visualization reveals clear sales trends across time.



Machine Learning prediction helps estimate future EV sales growth.
